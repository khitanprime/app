# Khitan Prime — Frontend (GitHub Pages)

Tampilan aplikasi manajemen klinik Khitan Prime. Backend: Google Apps Script (REST API, JSON).

- `index.html` — halaman utama (login + aplikasi)
- `css/style.css` — gaya
- `js/config.js` — **isi `GAS_URL` dengan URL Web App (`.../exec`)**
- `js/api.js` — pemanggil API (fetch, timeout, retry, idempotensi)
- `js/app.js` — logika aplikasi
- `assets/` — logo & video layar loading

Panduan lengkap: lihat `PANDUAN-INSTALASI.md`.
Folder ini adalah akar repository: `index.html` harus berada di akar.
